### SecretOnTheBoard

Городская доска быстрых объявлений — место, где каждый может поделиться новостью, предложением или тайным посланием. Но есть одна загадка, которую не может разгадать никто: «Объявление Часа». Оно висит в центре доски уже много лет, зашифрованное непробиваемым шифром. Говорят, тот, кто расшифрует его, получит доступ к древнему артефакту цифровой эры — флагу, скрывающему секреты. Сможете ли вы стать первым, кто остановит время и раскроет тайну?
