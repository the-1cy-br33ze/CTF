### SystemCore

Сайт с анимацией «Зелёного Потока» был частью эксперимента по визуализации сетевого трафика, разработанного студентами университета **NTI-2035**. После закрытия лаборатории проект забросили, но его копия неожиданно «ожила» на старом сервере, оставшемся без мониторинга.

Сейчас страница выглядит как артефакт эпохи раннего интернета — мерцающие символы, случайные вспышки красных меток и тихий обмен данными через забытый протокол. Никаких пояснений, только код и странные паттерны...
