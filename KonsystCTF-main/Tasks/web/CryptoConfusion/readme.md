### CryptoConfusion

Вы — участник программы раннего тестирования новой криптобиржи CryptoRich, которая позиционирует себя как платформу для «сверхбезопасных и инновационных транзакций». Сайт только что вышел из закрытой беты, и его разработчики активно рекламируют уникальные функции, включая интеграцию с блокчейн-сервисами и «непревзойденную систему аутентификации».

Однако среди тестеров ходят слухи, что в демо-версии скрыты недокументированные возможности. Ваша задача — исследовать платформу, изучить её механизмы и понять, насколько она соответствует заявленным стандартам.
