Подпись запросов

Для подписи запросов используйте JWT-токен в заголовке:
Authorization: Bearer <token>

Публичный ключ для проверки подписей:

Пример запроса

GET /v1/balance
Headers:
    Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

Response:
{
    "btc": "0.000000",
    "eth": "0.000000"
}
