Условия использования платформы CryptoRich

1. Общие положения

Сервис CryptoRich (далее — «Платформа») предоставляет пользователям возможность совершения операций с криптовалютами. Используя Платформу, вы соглашаетесь соблюдать настоящие Условия.

2. Права и обязанности

2.1. Пользователь обязуется:

  • Не использовать Платформу для незаконных операций
  • Не передавать учетные данные третьим лицам
  • Соблюдать правила AML/KYC

2.2. Платформа обязуется:

  • Обеспечивать бесперебойную работу сервиса
  • Хранить данные в зашифрованном виде
  • Информировать о технических работах за 24 часа

3. Ограничение ответственности

Компания не несет ответственности за убытки, возникшие в результате:

  • Действий третьих лиц
  • Изменения курсов криптовалют
  • Технических сбоев блокчейн-сетей

4. Контакты

По вопросам соблюдения Условий обращайтесь: legal@cryptorich.com.
