Классический и очень просто таск на Local File Inclusion.

Local File Inclusion (LFI) — это уязвимость в веб-приложениях, которая позволяет злоумышленнику получить доступ к локальным файлам сервера. Это происходит из-за недостаточной проверки ввода данных, что позволяет злоумышленнику манипулировать путями к файлам.

### Как работает LFI
1. Эксплуатация: Злоумышленник вводит относительный или абсолютный путь к файлу на сервере в параметрах запроса.
2. Исполнение: Сервер обрабатывает запрос и «включает» или отображает файл, к которому злоумышленник получил доступ.
3. Последствия: Это может привести к утечке чувствительной информации, например, исходного кода, файлов конфигурации и даже данных о пользователях.

### Пример
Запрос может выглядеть так:  
http://example.com/page.php?file=../../etc/passwd

Если проверка ввода недостаточная, сервер может открыть файл /etc/passwd.

Что в нашем случае, как и сработало по такой ссылке - 

http://ctf.hackatom.ru:3000/?file=..%2F..%2F..%2F..%2F..%2F..%2Fetc%2Fpasswd#projects
