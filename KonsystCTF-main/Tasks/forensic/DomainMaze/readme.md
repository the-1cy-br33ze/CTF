### DomainMaze

Файл `capture.pcap` был получен в ходе мониторинга сети после обнаружения аномальной активности на одном из корпоративных серверов. Аналитики предположили, что злоумышленник использовал DNS-запросы для скрытой передачи данных. Ваша задача — восстановить утечку и выявить скрытую информацию.
