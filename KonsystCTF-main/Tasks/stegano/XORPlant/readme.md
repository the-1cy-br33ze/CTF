Во время разбора архива старой ботанической экспедиции вы нашли три странных файла. Судя по записям, они относятся к исследованию редкого вида папоротника, который местные жители называли **«Зелёный Странник»**.

Учёные отмечали, что растение встречается только в одном удалённом районе, но точные координаты места в документах потерялись. В последней записи есть пометка:  
_«Данные фрагментарны. Ключ к разгадке — в файлах. Надеюсь, кто-нибудь доведёт это дело до конца...»_
